# DSH Project Icons 🖼️

This project is a plugin for the DeepSeek Harness (DSH) environment, designed to improve the organization and management of workspaces by adding custom icons to each project.

## Key Features
- **Custom Icons:** Ability to assign a unique image/icon to each workspace for easy visual identification.
- **Visibility Control:** Manage the visibility of workspaces in the sidebar.
- **Safe Removal:** Provides a secure mechanism for removing workspaces from the list.
- **Multi-language Support:** Interface supports both Arabic and English.

## Installation
This project is installed as a bundle within DeepSeek Harness using the `cordis.patch.yml` file.
