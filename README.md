# DSH Project Icons 🖼️

هذا المشروع هو إضافة (Plugin) لبيئة DeepSeek Harness (DSH)، تهدف إلى تحسين تنظيم وإدارة مساحات العمل (Workspaces) من خلال إضافة لمسات بصرية وأدوات تحكم في العرض.

## المميزات الأساسية
- **أيقونات مخصصة:** إمكانية تعيين أيقونة مميزة لكل مساحة عمل من مكتبة Lucide المدمجة أو رفع صورة خاصة من جهازك.
- **تأثيرات بصرية ذكية:** تظهر أيقونة المشروع بالألوان الكاملة عندما تكون إحدى جلساته محددة (نشطة)، وتتحول إلى اللون الرمادي (Grayscale) عند عدم تحديدها، مما يسهل معرفة المشروع النشال بصرياً.
- **تحكم في رؤية الشريط الجانبي:** إمكانية إخفاء أو إظهار مشاريع معينة من قائمة الشريط الجانبي دون التأثير على وجود مساحة العمل نفسها.
- **إزالة آمنة:** توفير خيار لإزالة المشروع من قائمة مساحات العمل دون حذف المجلدات أو الملفات أو الجلسات المرتبطة به.
- **دعم لغات متعددة:** واجهة كاملة تدعم اللغتين العربية والإنجليزية.

## طريقة التثبيت
يتم تثبيت هذا المشروع كحزمة (Bundle) داخل DeepSeek Harness عبر ملف `cordis.patch.yml`.

# DSH Project Icons 🖼️

This project is a plugin for the DeepSeek Harness (DSH) environment, designed to enhance the organization and management of workspaces through visual cues and visibility controls.

## Key Features
- **Custom Icons:** Assign a unique icon to each workspace using the bundled Lucide library or by uploading a custom image from your device.
- **Smart Visual Effects:** Project icons appear in full color when one of their sessions is currently selected (active) and turn grayscale when not selected, providing an immediate visual indicator of the active project.
- **Sidebar Visibility Control:** Hide or show specific projects from the sidebar list without affecting the existence of the workspace itself.
- **Safe Removal:** A secure option to remove a project from the workspace list without deleting its associated folders, files, or sessions.
- **Multi-language Support:** Full interface support for both Arabic and English.

## Installation
This project is installed as a bundle within DeepSeek Harness using the `cordis.patch.yml` file.
